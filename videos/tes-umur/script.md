# Tes umur — script

Narasi dan voice-over dari pengguna (92,9 s), tidak diubah. Mengikuti storyboard pengguna (8 adegan dengan teks layar): hook di gudang (anak SD menemukan kardus, skor 0/6), kaset (1/6), antena di tengah hujan dengan filter jadul (2/6), bapak gebetan mengangkat telepon (3/6), antre di wartel sambil melirik argo (4/6), magrib dan nama lengkap (5/6), Rp500 berubah jadi gunung jajanan (6/6), penutup haru main layangan saat senja; pertanyaan penutup di lapangan layangan. Papan di dunia yang sama dengan teks layar dihapus.

| Shot | Lokasi | Isi |
|---|---|---|
| 1 | Gudang | Anak SD masuk gudang dan menemukan kardus berdebu, skor 0/6 |
| 2 | Gudang | Anak menemukan kardus "HARTA KARUN AYAH" |
| 3 | Gudang | "Powerbank jadul?", Ayah tersedak kopi, kaset, pensil menggulung pita (1/6) |
| 4 | Rumah | Kakek di atap memutar antena, TV penuh semut, "Kiri dikit, Kek!" (2/6) |
| 5 | Dua rumah | Nelepon gebetan, bapaknya mengangkat: "Halo. Ini siapa?!" (3/6) |
| 6 | Wartel | Argo terus naik (4/6) |
| 7 | Kampung | Main sampai magrib, emak memanggil nama lengkap (5/6) |
| 8 | Warung | Rp500, jadi sultan bermahkota (6/6) |
| 9 | Gudang | "Ayah dulu nggak punya HP... nggak bosan?", Ayah mengambil layangan |
| 10-11 | Kampung (senja) | Main layangan bersama |
| 12 | Studio | Skor kamu berapa dari enam? |

**Catatan:** nama lengkap yang dipanggil emak ("MUHAMMAD RIZKY SAPUTRA!") hanya contoh; bisa diganti.
