# Mata kedutan — script

Narasi dan voice-over dari pengguna (77,3 s), tidak diubah. Belum ada storyboard: hanya caption kata-per-kata dan label di dunia.

| Shot | Lokasi | Isi |
|---|---|---|
| 1 | Kantor | Close-up Raka, kelopak mata berkedut, "DUG! DUG! DUG!" |
| 2 | Kantor | Rekan kantor jadi peramal (bola kristal): rezeki, ketemu orang jauh, mau sedih |
| 3 | Kantor | Kepercayaan turun-temurun; "apa kata ilmu pengetahuan?" |
| 4 | Lab | Model mata raksasa: otot kelopak berkedut, saraf "korsleting" |
| 5-6 | Kantor | Penyebab: awan stres, Zzz, cangkir kopi, silau layar |
| 7 | Kantor | Biasanya aman; tidur cukup, kurangi kopi, istirahatkan mata |
| 8 | Klinik | Dokter: > beberapa minggu, kelopak tertutup, menjalar → periksa ke dokter |
| 9 | Kantor | Raka menunggu rezeki, mata berkedut |
| 10-11 | Kantor | Bos membawa tumpukan berkas: lembur! (jam 23:30) |
| 12 | Kantor | Pertanyaan ke penonton |

**Cek fakta:** kedutan kelopak (eyelid myokymia) umumnya jinak, dipicu stres, kurang tidur, kafein, mata lelah, dan hilang sendiri; tanda perlu ke dokter: berlangsung lebih dari beberapa minggu, kelopak menutup penuh, menjalar ke bagian wajah lain (Mayo Clinic, AAO). Sesuai naskah.
